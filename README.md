# Flash Flood Prediction

This repository contains a Flash Flood Prediction prototype with backend (FastAPI) and frontend (Vite + React).

Frontend folder: `frontend`
Backend folder: `backend`

To run locally:

Backend:

```powershell
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Frontend:

```powershell
cd frontend
npm install
npm run dev
```
